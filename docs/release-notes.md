gdns v0.6.2 — исправление загрузки подписки feed.kislovs.ru.

Автор: Кислов Роман Сергеевич (@rkislov). Apache License 2.0.

- Для feed.kislovs.ru ключ ff_… в поле авторизации автоматически преобразуется в Authorization: Bearer <ключ>. Полные заголовки Bearer/Basic и настройки других поставщиков сохраняют своё значение.
- Адаптер этого источника пропускает небольшую примесь недоменных IoC в domains.txt. Пустой список или более 5% некорректных записей вызывают ошибку и не заменяют прежние данные. Обычный импорт остальных источников остаётся строгим.
- Сохраняются ограничения размера и числа доменов, HTTPS и запрет межсайтового перенаправления с ключом. Обновлена подсказка в редакторе фида.

DNSSEC, RFC 5011, схема SQL и форматы конфигурации не меняются. Локальная и доменная авторизация, secondary/AXFR и оптимизация сетевого пути находятся в отдельной работе и в этот срочный выпуск не включены.

Предварительные сборки Linux amd64/arm64: tar.gz, RPM Альт Linux / РЕД ОС, DEB Astra Linux, SHA256SUMS.
