GoDNS 0.7.1 — совместимость подписки Security Feed с feed.kislovs.ru.

GoDNS указывает `User-Agent: GDNS/1` в запросах к поставщику. Security Feed распознаёт клиент GoDNS. Доменный фид загружается по HTTPS с ключом подписки.

Доступны сборки Linux для amd64 и arm64. В комплект входят tar.gz, RPM для Альт Linux и РЕД ОС, DEB для Astra Linux и SHA256SUMS.

Автор — Кислов Роман Сергеевич. Лицензия — Apache 2.0.
