GoDNS 0.7.2 добавляет автообновление доменных фидов.

В разделе «Фиды и блокировки» можно задать интервал обновления в минутах. Панель показывает статус загрузки и время следующей попытки. При сбое GoDNS продолжает блокировать домены по последнему успешно загруженному списку. После обновления с 0.7.1 фиды сохраняют ручной режим, пока администратор не укажет интервал.

Доступны сборки Linux для amd64 и arm64. В комплект входят tar.gz, RPM для Альт Linux и РЕД ОС, DEB для Astra Linux и SHA256SUMS.
