gdns v0.6.1 — обновление поставки и документации.

Автор: Кислов Роман Сергеевич (@rkislov). Apache License 2.0.

- Обновлены версия по умолчанию в скрипте сборки и примеры установки RPM/DEB.
- В исходный снимок релиза включён окончательный протокол развёртывания и проверок v0.6.0: 48 изолированных нагрузочных прогонов без потерь и 32 проверки DNSSEC по UDP/TCP/DoH/DoT.
- DNS-ядро соответствует v0.6.0: совместное выделение сообщения и EDNS на попадании в кеш, параллельная запись в ячейки журнала, согласованная якорная пагинация. Новых алгоритмических оптимизаций в v0.6.1 нет.

Сохранены конфигурационный формат, SQL-схема, префикс метрик gdns_, DNSSEC-валидация и состояние RFC 5011. Для резервного копирования нужна полная база с управляемыми ключами; JSON-экспорт её не заменяет.

В тестовом secure-cache ответе v0.6.0/0.6.1 используется 6 вместо прежних 8 выделений памяти. На общем VPS значительного роста пикового сетевого QPS не обнаружено. [Профили, методика и полные результаты](https://github.com/rkislov/gdns/tree/main/benchmarks/2026-11-06/dnssec-cache) относятся к v0.6.0; алгоритмы DNS-ядра в v0.6.1 те же.

Предварительные сборки Linux amd64/arm64: tar.gz, RPM для Альт Linux и РЕД ОС, DEB для Astra Linux, SHA256SUMS. Упаковка не означает сертификацию ОС. Результаты развёртывания v0.6.0 не являются заявлением об установке v0.6.1 на сервер.
