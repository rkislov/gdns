gdns v0.5.0 — новое имя проекта (ранее GHole).

Автор: Кислов Роман Сергеевич (@rkislov). Apache License 2.0.

- Репозиторий https://github.com/rkislov/gdns; бинарник и systemd-служба gdns. Обновлены Go-модуль, интерфейс, документация, CI и имена пакетов.
- Новые пути /var/lib/gdns и /etc/gdns, переменные GDNS_ADMIN_TOKEN / GDNS_DATABASE_URL. Прежние GHOLE_* остаются резервными; новые имеют приоритет.
- Метрики используют префикс gdns_; внешние PromQL-запросы нужно обновить.
- SQL-таблицы сохраняют префикс ghole_ для совместимости существующей конфигурации и состояния RFC 5011. Переносится полная база, а не только JSON; автоматического переноса старой установки при установке пакета нет.
- Исторические измерения и имена старых артефактов сохранены. Оптимизации DNS v0.4.1 сохранены.

Linux amd64/arm64: tar.gz, RPM для Альт Linux / РЕД ОС и DEB для Astra Linux. Пакеты не означают сертификацию ОС. Выпуск предварительный. Инструкция переноса: https://github.com/rkislov/gdns/blob/main/docs/rename-to-gdns.md.
