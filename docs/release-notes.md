GHole v0.4.1 — производительность DNS и настраиваемые UDP-воркеры.

Автор: Кислов Роман Сергеевич (@rkislov). Apache License 2.0.

- Несколько UDP-сокетов через SO_REUSEPORT на Linux: автоматический выбор или 1–64 воркера, настройка через веб и фактическое число в обзоре. Изменение требует перезапуска.
- Меньше выделений памяти при локальных ответах, блокировках и попаданиях в кеш; таймер внешнего разрешения создаётся только при необходимости. DNSSEC, сроки RRSIG, split DNS и барьер отзыва RFC 5011 сохранены.
- Числовое хранение строк ограниченного журнала и получение страниц без прохода по всему кольцу. Формат API и якорная пагинация сохранены.
- Получение IP непосредственно из соединения, включая DoH; заголовки прокси не используются как источник доверия.
- Воспроизводимые микробенчмарки и изолированный сетевой стенд; результаты и ограничения опубликованы в benchmarks/2026-11-05/performance.

На общем пути AnswerAs с журналом микробенчмарки одного ядра показывают примерно двукратное ускорение. Это не обещание удвоения сетевого QPS. На общем трёхъядерном стенде эффект зависит от сценария: несколько воркеров помогают части UDP-нагрузок, максимальная нагрузка на DNSSEC-кеш показала регрессию, а холодная DNSSEC-проверка заметно не ускорилась. Все 120 ограниченных сетевых прогонов завершены без потерь.

Артефакты: Linux amd64/arm64 tar.gz, RPM-профили Альт Linux и РЕД ОС, DEB-профиль Astra Linux, SHA256SUMS. Go 1.27, без CGO; панель встроена в бинарник. Упаковка не означает сертификацию дистрибутива. Подписание собственных authoritative-зон пока не реализовано. RFC 5011 сохраняет обязательные периоды ожидания; реальный 30-дневный rollover данной установкой ещё не наблюдался.

Сборка CSS ограничена файлами веб-интерфейса через явный source(none). После публикации предварительной v0.4.0 проверка CI выявила различие CSS. Оно исправлено в v0.4.1; v0.4.0 на dev.kislovs.ru не устанавливалась.
