GHole v0.2.0 — локальная DNSSEC-валидация и управление через веб.

Автор: Кислов Роман Сергеевич (@rkislov). Apache License 2.0.

- Проверка DS → DNSKEY → RRSIG от корневых или частных trust anchors в recursive/forward/stub режимах.
- NSEC/NSEC3, NXDOMAIN/NODATA, wildcard, CNAME/DNAME, unsigned delegation и opt-out; SERVFAIL + EDE для ошибочных доказательств.
- Настройка anchors, исключений, CD, NSEC3 и тайм-аута без перезапуска. Загрузка текущих корневых DS IANA в редактор по проверенному HTTPS.
- Изоляция CD/view-кеша, TTL до истечения подписи/цепочки, ограничение криптографических затрат, Prometheus и индикаторы DNSSEC.
- Детерминированные криптографические тесты, проверка race/vet и отдельные живые интернет-проверки обоих режимов.

Артефакты: Linux amd64/arm64 tar.gz; RPM-профили Альт Linux и РЕД ОС; DEB-профиль Astra Linux; SHA256SUMS. Бинарник собирается Go 1.27 без CGO, веб-ресурсы встроены. Поддержка упаковки не означает сертификацию дистрибутива.

Автоматическое обновление anchors по RFC 5011 и подписание собственных authoritative-зон пока не реализованы. Корневые ключи нужно сопровождать через панель или обновления программы. Исторический нагрузочный отчёт v0.1.0 в docs/load-test-2026-11-05.md не является измерением производительности DNSSEC.
