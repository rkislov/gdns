gdns v0.7.0 — пользователи, доменный вход и secondary-зоны.

Автор: Кислов Роман Сергеевич (@rkislov). Apache License 2.0.

- Локальные пользователи с Argon2id, роли admin/operator/viewer, управление через веб. Первоначальный пароль admin создаётся в `<config>.admin-password` (0600). Прежний административный токен продолжает работать.
- LDAP / Active Directory через LDAPS или StartTLS с проверкой сертификата, пользовательским bind и назначением ролей по группам. Все параметры настраиваются через веб. Пароли доменных пользователей не сохраняются; локальный администратор остаётся для резервного входа.
- HttpOnly/SameSite-сессии, CSRF-защита, ограничение попыток входа и одновременных вычислений паролей. SQLite и PostgreSQL сохраняют настройки доступа отдельно от DNS-конфигурации.
- Primary AXFR по TCP/DoT: ACL с запретом по умолчанию и опциональный TSIG HMAC-SHA256. Передача учитывает представление и сплит-записи по адресу secondary.
- Secondary: первоначальный AXFR, SOA refresh/retry/expire, атомарное сохранение копии, статус и ручное обновление через веб. После expire — SERVFAIL. Неполная передача и откат serial не заменяют рабочую копию. IXFR и NOTIFY пока не реализованы; исходящий secondary использует TCP.
- При изменении primary-записей SOA serial увеличивается автоматически, если пользователь не задал более новый.
- Профилирование сетевого пути и результаты сравнения опубликованы в `benchmarks/2026-11-06/network-buffers`. Пул буферов отклонён по результатам замеров. Снижено число выделений памяти при создании локальных DNS-ответов.
- Включено исправление подписок feed.kislovs.ru из v0.6.2.

Проверки: race-тесты, SQLite/PostgreSQL, TLS-фикстуры LDAP/StartTLS, роли/CSRF, AXFR/TSIG и многопакетные передачи, expire и атомарная публикация копии, UDP/TCP/DoH/DoT. Реальный домен на dev.kislovs.ru пользователь настраивает через веб после обновления.

Предварительные сборки Linux amd64/arm64: tar.gz, RPM Альт Linux / РЕД ОС, DEB Astra Linux, SHA256SUMS. Нативная установка каждой целевой российской ОС требует отдельной проверки; dev-сервер работает на Ubuntu.
