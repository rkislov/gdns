# Переименование GHole → gdns

С v0.5.0 репозиторий: https://github.com/rkislov/gdns. Для старого checkout: `git remote set-url origin https://github.com/rkislov/gdns.git`. Бинарник, Go-модуль, systemd unit и системный пользователь теперь называются gdns. Лицензия Apache-2.0 и автор Кислов Роман Сергеевич сохранены.

## Совместимость

SQL-таблицы `ghole_*` сохраняют имена: это формат существующего хранилища, включая ключи RFC 5011, таймеры и CAS-ревизию. Новый бинарник открывает прежнюю SQLite/PostgreSQL базу. Один активный процесс на базу: синхронизации DNS-снимков между процессами нет.

Для запуска без переноса файлов явно передайте прежние `-config` и `-database`. Новый default — `gdns.json`; запуск без явных путей в старой папке может создать отдельную установку. `GDNS_ADMIN_TOKEN` и `GDNS_DATABASE_URL` имеют приоритет над `GHOLE_ADMIN_TOKEN` и `GHOLE_DATABASE_URL`; старые переменные остаются резервными.

## Перенос systemd-установки

1. Сохраните старый бинарник, unit/drop-ins, конфигурацию, токен, сертификаты и полную базу. Для работающей SQLite используйте backup API: копия файла без WAL может потерять данные. JSON-экспорт не включает всё состояние RFC 5011. PostgreSQL требует согласованной резервной копии.
2. Установите пакет gdns: он создаёт пользователя и unit, но не запускает DNS автоматически. Выполните `-check` на копии базы с доступными TLS-файлами.
3. Остановите и отключите ghole. Создайте окончательную копию SQLite в `/var/lib/gdns/gdns.db`, перенесите конфигурацию и токен в `/var/lib/gdns/config.json` и `config.json.token`. Владелец gdns:gdns, приватные права. PostgreSQL можно оставить на прежней базе с остановленной старой службой.
4. Скопируйте TLS в `/etc/gdns/tls` (root:gdns, ключ 0640), обновите пути в конфигурации и выполните явный импорт полной конфигурации. Сохраните ACL, зоны, фиды, DNSSEC и управляемые ключи. Обновите drop-ins, EnvironmentFile и certbot deploy hook для путей и службы gdns.
5. Запустите `systemctl enable --now gdns`. Проверьте UDP/TCP/DoH/DoT, веб, воркеры, журнал и Prometheus. Сравните сериализованное состояние `ghole_dnssec_managed`, ревизию и расписание RFC 5011 с резервной копией. Сохраните прежнюю установку до завершения проверки.

Пакет не переносит данные автоматически. Для возврата остановите gdns и запустите прежнюю службу с её сохранёнными данными; изменения, внесённые после переключения, требуют отдельного переноса.

## Метрики и интерфейс

Префикс Prometheus изменён с `ghole_` на `gdns_`: обновите внешние запросы, правила и панели. Адрес /metrics и метки сохранены. Старые временные ряды остаются до истечения retention Prometheus. Веб использует новый ключ sessionStorage; при необходимости войдите прежним токеном. Исторические протоколы, версии, контрольные суммы и пути сохранены как свидетельства прежних испытаний.
