# Совместимость сборок

Проверка проводится 5 ноября 2026 года. Сборка выполняется с `CGO_ENABLED=0`, поэтому исполняемый файл не зависит от версии glibc целевого дистрибутива.

- Linux amd64: бинарник и пакет установлены на Ubuntu 24.04, служба systemd работает непривилегированным пользователем, нативный HTTPS с сертификатом Let's Encrypt проверен.
- Альт Linux 11 / p11 amd64: RPM читается штатным rpm; статический бинарник запускается в официальном контейнере, конфигурация и SQLite успешно инициализируются. Проверка установки с зависимостями выполняется отдельно.
- Astra Linux SE 1.8 amd64: официальный контейнер получен; DEB распознаётся dpkg. Для установки нужен systemd, который отсутствует в минимальном UBI-образе; проверка с установленной зависимостью выполняется отдельно.
- РЕД ОС amd64: RPM собран; запуск в целевой ОС не подтверждён, так как Docker отклонил TLS-сертификат официального реестра. Проверка TLS не отключалась.
- Linux arm64: архивы, RPM и DEB собраны кросс-компиляцией. Нативный запуск этих артефактов на целевых системах пока не проверен.

Контейнерный smoke-тест использует ядро хоста и не является проверкой загрузки полного дистрибутива, systemd как PID 1, SELinux, мандатных механизмов Astra или сертифицированной редакции ОС. Само наличие пакета не означает сертификацию совместимости.
