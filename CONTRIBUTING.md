# Участие в GHole

Автор и единственный сопровождающий основного репозитория — **Кислов Роман Сергеевич (@rkislov)**.

Предложения, вопросы и сообщения об ошибках направляйте через GitHub Issues. Изменения кода предлагайте pull request из собственного fork. Право записи в основной репозиторий и принятия/слияния изменений остаётся только у @rkislov. Право записи внешним участникам не предоставляется; автоматическое слияние не используется.

Перед PR выполните `make test`, опишите проблему, изменение поведения и проверку. Не включайте пароли, токены, приватные ключи, базы, журналы с данными клиентов или конфигурации боевых систем. Изменения UI должны включать пересобранный `internal/web/static/style.css`.
